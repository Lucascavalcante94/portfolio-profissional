# 🚀 Portfólio Profissional Interativo
## 📌 Objetivo do projeto

Este projeto tem como objetivo desenvolver um **portfólio profissional interativo**, apresentando minha trajetória, experiências, competências técnicas e objetivos profissionais.

Desenvolvido como projeto acadêmico, permite aplicar conceitos fundamentais de desenvolvimento web e programação, transformando uma interface inicialmente estática em uma experiência dinâmica e interativa.

O projeto também representa a integração entre minha experiência em Automação Industrial e minha formação em Engenharia de Software.

🎯 Funcionalidades
Apresentação do perfil profissional;
Exibição de experiências e competências;
Navegação entre diferentes seções;
Interações com elementos da interface;
Manipulação do DOM;
Tratamento de eventos;
Utilização do Local Storage;
Formulário de contato com validação;
Interface responsiva.
🛠️ Tecnologias utilizadas
HTML5
CSS3
JavaScript
DOM (Document Object Model)
Local Storage
Git
GitHub
📚 O que foi aprendido

Durante o desenvolvimento, foram aplicados conceitos fundamentais de desenvolvimento web e programação, incluindo:

Estruturação de páginas com HTML;
Organização e estilização com CSS;
Desenvolvimento de funcionalidades com JavaScript;
Manipulação do DOM;
Criação e tratamento de eventos;
Armazenamento de dados utilizando Local Storage;
Validação de formulários;
Organização e documentação de projetos;
Controle de versão utilizando Git e GitHub.
💡 Desafios encontrados

Um dos principais desafios foi transformar uma interface estática em uma aplicação interativa, compreendendo como HTML, CSS e JavaScript trabalham em conjunto para construir uma aplicação funcional.

O projeto também permitiu compreender a importância da organização, documentação e versionamento durante o desenvolvimento de software.
